Copied `dsp.rs`, `macros.rs`, `util.rs`, `util/audio.rs`, `util/audio/*`, and all six visuals' `processor.rs` files: spectrum, oscilloscope, spectrogram, waveform, stereometer, and loudness. All six processor files were checked byte-for-byte against this pinned commit on 2026-10-07 before cursor work. The oscilloscope snapshot now adds capture-duration and cycle-frequency metadata, and exposes the existing cycle-rate accessor for native cursor readouts. Trigger and measurement algorithms are unchanged; the other five processor files remain unchanged. `util.rs` omits the UI-only color module. Module roots expose the six processors. `lib.rs` is Audioglass's PCM ingestion/configuration/snapshot bridge; generated tones exist only in test fixtures.

The original Iced/wgpu renderer is not included. Native AppKit consumes processor snapshots and draws white straight segments. The spectrogram processor is unchanged. `spectrogram_raster.rs` (Audioglass, not upstream) reproduces upstream's GPU rasterization on the CPU: reassigned points are splatted one display point square at their time-offset column, linear power accumulates per physical pixel, then `reassigned_power_scale`, dB conversion and the -140 dB floor apply as in `spectrogram.wgsl`; floor, spectral tilt and the heat palette are applied in Audioglass's Metal shader. Deliberate differences: time placement is at whole-column resolution (upstream places 2x splats at half-point steps); reassigned points whose time estimate lies more than one hop outside the analysis window are dropped (upstream draws these near-silent speckles); the newest half-window of reassigned columns is withheld until complete; classic rows that span several FFT bins show the bins' peak instead of sampling the row centre. Waveform and spectrogram histories are bounded by the bridge. True peak display decay is added by the bridge; upstream measurement is unchanged. Spectrum configuration maps directly to upstream settings, including raw, exponential, and peak-hold averaging.

Loudness tests use the upstream ebur128 reference dependency. Cargo.lock pins resolved dependencies. See ../FEATURES.md for remaining parity work.
